# Οδηγίες δοκιμών — Timologio Downloader + e‑Τιμολόγιο Pro 0.3.0

Πώς στήνεται και δοκιμάζεται το ενοποιημένο προϊόν. Το repo είναι **private**,
αλλά ισχύει ένας κανόνας χωρίς εξαίρεση:

> ⚠️ **Κανένα κλειδί ΑΑΔΕ δεν γράφεται σε αρχείο του repo.** Το `config.php`,
> το `.enckey` και οι βάσεις είναι gitignored. Ό,τι μπει μία φορά στο git μένει
> για πάντα στο ιστορικό, ακόμη και αν διαγραφεί αργότερα, και εκτίθεται σε
> όποιον αποκτήσει πρόσβαση στο repo ή σε ένα clone.

---

## 1. Τι είναι το 0.3.0

Ένα εκτελέσιμο, δύο εφαρμογές στο ίδιο παράθυρο:

- **Λήψη Παραστατικών myDATA** (ο γνωστός Downloader)
- **e‑Τιμολόγιο Pro** — έκδοση/διαχείριση παραστατικών πάνω στο e‑timologio της
  ΑΑΔΕ, με **native** οθόνες (όχι browser)

Η έκδοση συνεχίζει τη σειρά του Downloader (0.2.28 → **0.3.0**), ώστε οι
υπάρχοντες χρήστες να τη λάβουν κανονικά ως ενημέρωση.

---

## 2. Εγκατάσταση για δοκιμή (standalone, πλευρά λογιστή)

1. Χτίσε τον installer:
   ```powershell
   powershell -ExecutionPolicy Bypass -File desktop\installer\build.ps1
   ```
   Παράγει `desktop\dist\installer\TimologioDownloader-0.3.0-setup.exe` (~55 MB).
   Το πρώτο build κατεβάζει μια φορητή PHP (~25 MB μετά το κλάδεμα) στο
   `desktop\installer\php\` — δεν μπαίνει στο git.

2. Τρέξε τον installer και διάλεξε:
   - **Ρόλος:** «Αυτόνομος υπολογιστής»
   - **Φάκελος δεδομένων:** άσε το προεπιλεγμένο `Έγγραφα\Παραστατικά myDATA`

3. Άνοιξε την εφαρμογή. Στο πλαϊνό μενού, ενότητα **ΕΦΑΡΜΟΓΕΣ → e‑Τιμολόγιο Pro**.

Δεν χρειάζεται εγκατεστημένη PHP: το backend ταξιδεύει μέσα στο πρόγραμμα.

## 3. Στοιχεία σύνδεσης

### 3.1 Τοπική λειτουργία (offline) — αυτόματη σύνδεση

Στο offline mode η εφαρμογή **συνδέεται μόνη της**. Την πρώτη φορά παράγει έναν
τυχαίο κωδικό διαχειριστή και τον αποθηκεύει στο:

```
<φάκελος δεδομένων>\etimologio\service.json
```

Άνοιξέ το αν θέλεις να μπεις και από browser στο τοπικό backend (το `service.json`
γράφει και τη θύρα). Ο κωδικός είναι **ανά εγκατάσταση** — δεν υπάρχει κοινός.

### 3.2 Δοκιμαστικός λογαριασμός εφαρμογής (web / thin client)

Για τα σενάρια όπου στήνεις backend με το χέρι (τοπικός PHP server ή VPS), όρισε
στο `config.php`:

```php
const MASTER_ADMIN_EMAIL    = 'admin@example.com';
const MASTER_ADMIN_PASSWORD = 'Test-1234-strong';
```

Αυτά είναι **δοκιμαστικά** στοιχεία της εφαρμογής, όχι της ΑΑΔΕ. Δημιουργούνται
στη βάση την πρώτη εκτέλεση· μετά μπορείς να αφαιρέσεις τον κωδικό από το config.
**Σε παραγωγή βάλε άλλα.**

### 3.3 Στοιχεία ΑΑΔΕ — πού μπαίνουν

Ποτέ σε αρχείο του repo. Δύο τρόποι:

- **Από το UI** (ο κανονικός): e‑Τιμολόγιο Pro → **Διαχείριση** → προσθήκη
  λογαριασμού με ΑΦΜ / username / subscription key. Αποθηκεύονται
  **κρυπτογραφημένα** στη βάση.
- **Τοπικά για dev:** αντίγραψε το `config.example.php` σε `config.php` (είναι
  gitignored) και συμπλήρωσε τον πίνακα `$ACCOUNTS`.

Ο λογαριασμός δοκιμών (ΑΦΜ **802576637**) έχει πραγματικά παραστατικά. Το
subscription key **δεν** αναγράφεται εδώ — ζήτησέ το ή πάρ' το από το Infisical.

## 4. Ασφαλής δοκιμή έκδοσης

Το e‑Τιμολόγιο έχει τρεις λειτουργίες σε κάθε οθόνη έκδοσης:

| Κουμπί | Τι κάνει | Ασφαλές; |
|---|---|---|
| **Αποθήκευση πρόχειρου** | σώζει πρόχειρο στο e‑timologio | ✅ κανένα ΜΑΡΚ |
| **Προεπισκόπηση** | σώζει πρόχειρο + επιστρέφει το πραγματικό PDF | ✅ κανένα ΜΑΡΚ |
| **Έκδοση** (κόκκινο) | **υποβάλλει στην ΑΑΔΕ και παίρνει ΜΑΡΚ** | ❌ μη αναστρέψιμο |

Για τις δοκιμές χρησιμοποίησε μόνο τα δύο πρώτα. Ένα εκδοθέν παραστατικό **δεν
διαγράφεται** — ακυρώνεται μόνο με συσχετιζόμενο πιστωτικό.

Μετά τις δοκιμές, σβήσε τα πρόχειρα από **Πρόχειρα → Διαγραφή**.

## 5. Λίστα ελέγχου

**Downloader:** λήψη παραστατικών · φίλτρα στηλών · εξαγωγή Excel/CSV · μαζική
εκτύπωση · εξαγωγή ZIP.

**Μετάβαση:** εναλλαγή Downloader ↔ e‑Τιμολόγιο · δεξί κλικ σε πελάτη →
«Άνοιγμα στο e‑Τιμολόγιο Pro».

**e‑Τιμολόγιο (14 ενότητες):** Έκδοση · Παραστατικά (αναζήτηση, μαζική εκτύπωση,
ZIP) · Πελάτες · Καρτέλα · Μαζική έκδοση · Ακύρωση/Πιστωτικό · Πρόχειρα · Είδη ·
Σειρές · Πληρωμές (+ extrait τράπεζας) · Στατιστικά (δεύτερο άνοιγμα = στιγμιαίο,
από cache) · Προγραμματισμός · Ειδοποιήσεις · Ρυθμίσεις (**2FA: το QR πρέπει να
εμφανίζεται** — σπάει μόνο σε πακεταρισμένο build) · Διαχείριση.

**Εμφάνιση:** φωτεινό/σκοτεινό θέμα σε όλες τις οθόνες · διακόπτης «Βοηθητικά
μηνύματα» · Ξενάγηση · Εγχειρίδιο PDF.

**Ενημέρωση:** εγκατάσταση 0.2.28 → ενημέρωση σε 0.3.0, με φάκελο δεδομένων που
έχει **κενό στο όνομα** («Παραστατικά myDATA») — εκεί έσπαγε πριν το 0.2.27.

## 6. Ανάπτυξη

```bash
# Tests (χωρίς οθόνη)
QT_QPA_PLATFORM=offscreen PYTHONPATH=desktop/src \
  python -m pytest desktop/tests -q

# Έλεγχος σύνταξης PHP — και στα ΔΥΟ αντίγραφα
php -l etimologio.php && php -l desktop/backend/etimologio/etimologio.php
```

Το PHP υπάρχει σε δύο σημεία: στη **ρίζα** (αυτό σερβίρει το Docker/VPS) και στο
`desktop/backend/etimologio/` (αυτό πακετάρεται στην εφαρμογή). **Πρέπει να
μένουν ίδια** — άλλαξε στη ρίζα και αντίγραψε.

Για τοπικό PHP server χωρίς εγκατεστημένη PHP, χρησιμοποίησε τη φορητή που
κατεβάζει το build:

```bash
desktop/installer/php/php.exe -c desktop/installer/php/php.ini \
  -d curl.cainfo=<απόλυτη διαδρομή>/cacert.pem \
  -S 127.0.0.1:8199 -t .
```

Το `curl.cainfo` **πρέπει** να δοθεί απόλυτο: η PHP το λύνει ως προς τον τρέχοντα
φάκελο (όχι ως προς το ini) και μια σχετική τιμή δίνει curl error 77 σε κάθε
κλήση προς την ΑΑΔΕ.
