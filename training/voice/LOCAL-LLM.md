# Τοπικό LLM στον βοηθό — σχέδιο αναβάθμισης

Τι θα χρειαστεί για να μπει ένα μοντέλο **μέσα** στην εφαρμογή, χωρίς δίκτυο και
χωρίς να χαλάσει ό,τι δουλεύει σήμερα. Γράφτηκε ώστε να μπορεί να εκτελεστεί
αργότερα, από μηδενική μνήμη της συζήτησης.

> Αυτό το αρχείο αφορά **μόνο τον δρομολογητή** (κείμενο → JSON ενέργεια). Για
> το ποια μοντέλα ακοής και φωνής να χρησιμοποιηθούν, με μεγέθη, ταχύτητες σε
> CPU και τον τρόπο εκπαίδευσης στη δική σου φωνή, δες το **[MODELS.md](MODELS.md)**.

---

## 1. Πού βρισκόμαστε σήμερα

| Κομμάτι | Υλοποίηση | Αρχείο |
|---|---|---|
| Ακοή | whisper.cpp `ggml-small-q5_1` | [etimologio.php:4185](../../etimologio.php:4185) |
| Δρομολογητής (desktop) | regex | [assistant.py](../../desktop/src/timologio/etimologio/assistant.py) |
| Δρομολογητής (web) | regex σε JS | `cbHandle` στο [app.php](../../app.php) |
| Εκτέλεση εντολών | Qt signals → κέλυφος | [shell.py `_assistant_command`](../../desktop/src/timologio/etimologio/shell.py) |
| Φωνή | Piper `el_GR-joy-medium` | [speech.py](../../desktop/src/timologio/etimologio/speech.py) |

Μέτρηση, όχι εντύπωση — τρέξε:

```bash
python training/voice/eval_router.py
```

Στις 804 εντολές του `intents_el.json` (`--el` / `--en` για ανά γλώσσα):

```
ελληνικά   620/701   88.4%
αγγλικά     27/103   26.2%      ← ο βοηθός έχει αγγλική λειτουργία· ο router όχι
ΣΥΝΟΛΟ     647/804   80.5%
```

Αυτό που μένει είναι το πραγματικό κέρδος ενός μοντέλου:

* ελεύθερη διατύπωση με **όνομα** αντί για ΑΦΜ («κόψε τιμολόγιο στη Μεγατέκ για 200»),
* λέξεις που **άκουσε λάθος** το whisper («κάνε ξενάγιση», «δούλεψε στην ετερεία»),
* εντολές που ζητούν **οριστική έκδοση** και πρέπει να απαντηθούν με άρνηση, όχι με «δεν κατάλαβα».

## 2. Η αρχιτεκτονική-στόχος

Το μοντέλο μπαίνει ως **δεύτερη γραμμή**, όχι ως αντικαταστάτης:

```
κείμενο ─► regex router ──(βρήκε)──► ενέργεια
              │
           (δεν βρήκε)
              ▼
        τοπικό LLM ─► JSON ─► επικύρωση ─► ενέργεια
                                 │
                            (άκυρο JSON)
                                 ▼
                       «δεν το κατάλαβα»
```

Γιατί όχι αντικατάσταση: ο regex είναι 0 ms και ντετερμινιστικός· το «πήγαινε
στα πρόχειρα» δεν έχει λόγο να περάσει από 400 MB βαρών. Και όταν το μοντέλο
λείπει (server, παλιό build, χρήστης που δεν το κατέβασε), ο βοηθός συνεχίζει να
δουλεύει όπως σήμερα.

## 3. Το συμβόλαιο — τι επιστρέφει το μοντέλο

**Μόνο ένα JSON αντικείμενο**, με τα κλειδιά του [`Reply`](../../desktop/src/timologio/etimologio/assistant.py):

| Κλειδί | Τιμή | Ποιος το εκτελεί |
|---|---|---|
| `navigate` | `issue`, `documents`, `bulk`, `customers`, `products`, `series`, `drafts`, `credit`, `payments`, `schedule`, `stats`, `notifications`, `settings`, `companies`, `admin`, `card` | `shell.open_section` / `showView` |
| `command` | `manual`, `tour`, `backup`, `logout`, `palette`, `refresh`, `home`, `back`, `speak:on`, `speak:off`, `card:<ΑΦΜ>`, `company:<ΑΦΜ>` | `shell._assistant_command` |
| `dialog` + `prefill` | `customer` \| `product` | `shell._assistant_dialog` |
| `fetch` | `stats:year`, `stats:month`, `notifications`, `customers_count`, `products_count` | `shell._assistant_fetch` |
| `draft` | `{vat, name, item, price, qty, withholding_pct}` | `issue.prepare_draft` — **πάντα πρόχειρο** |
| `say` | ελεύθερο κείμενο | το panel |

Ό,τι δεν είναι σε αυτόν τον πίνακα **απορρίπτεται πριν εκτελεστεί**. Το μοντέλο
δεν είναι έμπιστη πηγή εντολών: είναι πρόταση που περνά από φίλτρο.

## 4. Δεδομένα εκπαίδευσης

| Αρχείο | Ρόλος | Πλήθος |
|---|---|---|
| [`intents_el.json`](intents_el.json) | εντολή → JSON ενέργεια (ελληνικά + αγγλικά) | 804 |
| [`tts_normalizer_el.json`](tts_normalizer_el.json) | κείμενο → εκφώνηση (ΑΦΜ ανά 2ψήφια κ.λπ.) | 890 |

Και τα δύο παράγονται ξανά με:

```bash
python training/voice/build_intents.py
python training/voice/build_dataset.py
```

**Τα συνθετικά δεδομένα δεν αρκούν για παραγωγή.** Το πραγματικό σύνολο μαζεύεται
από την ίδια την εφαρμογή: στο `?stt=1` ([etimologio.php:4185](../../etimologio.php:4185))
πρόσθεσε προαιρετική καταγραφή `{ό,τι ακούστηκε, τι έκανε ο χρήστης μετά}` σε
JSONL μέσα στον φάκελο δεδομένων, με ρητή συγκατάθεση και **χωρίς αποστολή
πουθενά**. 300-500 αληθινές εντολές αξίζουν όσο 5.000 συνθετικές.

## 5. Εκπαίδευση

```bash
pip install unsloth
python training/voice/train_unsloth.py      # άλλαξε DATA → intents_el.json
```

* **Μοντέλο βάσης**: `unsloth/Qwen3-0.6B` (q4_k_m ≈ 400 MB) ή `Qwen3-1.7B`
  (≈ 1.1 GB) όταν προτεραιότητα είναι η ακρίβεια.
* **Ένα LoRA ή δύο;** Δύο εργασίες (δρομολόγηση + εκφώνηση) χωράνε σε ένα
  μοντέλο αν το `instruction` τις ξεχωρίζει — και ένα μοντέλο σημαίνει μία φορά
  φόρτωμα στη μνήμη. Ξεκίνα ενωμένα· χώρισέ τα μόνο αν η μία εργασία χαλάει την άλλη.
* **Θερμοκρασία 0** στην εκτέλεση. Ο δρομολογητής δεν έχει λόγο να είναι δημιουργικός.
* **Γραμματική GBNF**: το llama.cpp δέχεται `--grammar-file` που **επιβάλλει** έγκυρο
  JSON με τα επιτρεπτά κλειδιά. Είναι ο φθηνότερος τρόπος να μη δεις ποτέ
  μισοτελειωμένο JSON — γράψε τη γραμματεία από τον πίνακα του §3.

## 6. Ενσωμάτωση, βήμα-βήμα

1. **Πακετάρισμα.** `llama-cli.exe` + `.gguf` στο `desktop/installer/llm/`.
   Στο [`timologio.spec`](../../desktop/installer/timologio.spec) αντίγραψε το μοτίβο
   του `WHISPER`: λίστα αρχείων που κρατάμε, ώστε ένας παλιός φάκελος build να μη
   φέρνει 2 GB παραδειγμάτων.
2. **Ανακάλυψη διαδρομών.** Πρόσθεσε `llm`/`llm_model` στο `voice_engine()`
   ([etimologio.php:3973](../../etimologio.php:3973)) — ίδιος μηχανισμός με Piper/whisper:
   πρώτα σταθερά του `config.php`, μετά συμβατικές θέσεις.
3. **Σταθερές.** Στο [`service.py`](../../desktop/src/timologio/etimologio/service.py),
   δίπλα στα `PIPER_EXE`/`WHISPER_EXE`, γράψε `LLM_EXE` και `LLM_MODEL`.
4. **Endpoint.** `?llm=1&text=…` στο `etimologio.php`, δίπλα στο `?tts=1`:
   `proc_open` με `--grammar-file`, timeout, και **501 όταν λείπει το μοντέλο** —
   ίδια συμπεριφορά με τη φωνή, ώστε το UI να ξέρει ήδη τι να κάνει.
5. **Desktop.** Στο `Assistant.handle()`, στο σημείο που σήμερα επιστρέφει
   «Δεν το κατάλαβα», κάλεσε το μοντέλο. Ο `Assistant` **δεν κάνει δίκτυο ούτε
   subprocess μόνος του** (είναι ο λόγος που δοκιμάζεται χωρίς Qt): πέρασέ του
   ένα `resolver: Callable[[str], dict | None]` στον constructor, και δώσε την
   πραγματική υλοποίηση από το `assistant_panel.py`.
6. **Web.** Στο `cbHandle`, στο ίδιο σημείο (πριν το τελικό «Δεν το κατάλαβα»),
   `await api({llm:1,text:t})` και εκτέλεση μέσα από τον ίδιο έλεγχο του §7.
7. **Επικύρωση.** Μία συνάρτηση, κοινή λογική σε Python και JS:
   άγνωστο κλειδί → πέταξέ το· `navigate` εκτός λίστας → άκυρο· `command` εκτός
   λίστας → άκυρο· `draft` χωρίς `vat`/`name` → άκυρο· οτιδήποτε μυρίζει οριστική
   έκδοση → άρνηση με το σταθερό μήνυμα.
8. **Δοκιμές.** `eval_router.py` με τον resolver του μοντέλου, και νέα tests στο
   [`test_assistant.py`](../../desktop/tests/test_assistant.py) με fake resolver —
   ένα που επιστρέφει έγκυρο JSON, ένα σκουπίδια, ένα που ζητά οριστική έκδοση.

## 7. Όρια που δεν διαπραγματεύονται

* **Ποτέ οριστική έκδοση.** Το ΜΑΡΚ βγαίνει μόνο από το κόκκινο κουμπί, με
  ανθρώπινη επιβεβαίωση. Το `intents_el.json` περιέχει παραδείγματα *άρνησης*
  ακριβώς γι' αυτό.
* **Τίποτα δεν φεύγει από το μηχάνημα.** Ίδιος κανόνας με Piper/whisper: τα λόγια
  του λογιστή και τα ΑΦΜ των πελατών δεν ταξιδεύουν.
* **Ο regex μένει.** Είναι το δίχτυ ασφαλείας όταν το μοντέλο λείπει ή αργεί.
* **Προϋπολογισμός μεγέθους.** Ο installer είναι ήδη 452 MB. Ένα 0.6B q4_k_m τον
  πάει ~850 MB. Αν αυτό δεν είναι αποδεκτό, το μοντέλο γίνεται **προαιρετικό
  κατέβασμα** — ίδιο μοτίβο με το ελληνικό Vosk στο `build.ps1 -WithVoice`.

## 8. Σειρά υλοποίησης

| Φάση | Τι | Κέρδος | Κόστος |
|---|---|---|---|
| 1 ✅ | Διευρυμένες εντολές σε regex (αυτό το commit) | 74% → 87% κάλυψη | 0 MB |
| 2 | Κανονικοποιητής εκφώνησης **ως κώδικας** (`say_code`, `money` σε PHP/Python) | σωστά ΑΦΜ και ποσά στη φωνή | 0 MB |
| 3 | Whisper fine-tune στο λεξιλόγιο (Unsloth — δες [MODELS.md](MODELS.md) §1) | λιγότερα «τυστικά» | 0 MB (ίδιο μέγεθος μοντέλου) |
| 4 | LLM δρομολογητής ως fallback | ελεύθερος λόγος | ~400 MB |

Οι φάσεις 2 και 3 δίνουν το μεγαλύτερο μέρος του αποτελέσματος χωρίς megabytes.
Η 4 μπαίνει όταν υπάρχουν αληθινά δεδομένα από τη φάση 3 — όχι πριν.
