# Τοπικό LLM στον βοηθό — σχέδιο αναβάθμισης

Τι θα χρειαστεί για να μπει ένα μοντέλο **μέσα** στην εφαρμογή, χωρίς δίκτυο και
χωρίς να χαλάσει ό,τι δουλεύει σήμερα. Γράφτηκε ώστε να μπορεί να εκτελεστεί
αργότερα, από μηδενική μνήμη της συζήτησης.

> Αυτό το αρχείο αφορά **μόνο το «μυαλό»** (κείμενο → JSON: ενέργεια ή
> απάντηση). Για
> το ποια μοντέλα ακοής και φωνής να χρησιμοποιηθούν, με μεγέθη, ταχύτητες σε
> CPU και τον τρόπο εκπαίδευσης στη δική σου φωνή, δες το **[MODELS.md](MODELS.md)**.

---

## 1. Πού βρισκόμαστε σήμερα

| Κομμάτι | Υλοποίηση | Αρχείο |
|---|---|---|
| Ακοή | whisper.cpp `ggml-small-q5_1` | [etimologio.php:4185](../../etimologio.php:4185) |
| Δρομολογητής (desktop) | regex | [assistant.py](../../desktop/src/timologio/etimologio/assistant.py) |
| Δρομολογητής (web) | regex σε JS | `cbHandle` στο [app.php](../../app.php) |
| Εκτέλεση εντολών | Qt signals → κέλυφος | [shell.py `_assistant_command`](../../desktop/src/timologio/etimologio/shell.py) |
| Φωνή | Piper `el_GR-joy-medium` | [speech.py](../../desktop/src/timologio/etimologio/speech.py) |

Μέτρηση, όχι εντύπωση — τρέξε:

```bash
python training/voice/eval_router.py
```

Δύο μετρήσεις, και **μόνο η δεύτερη λέει την αλήθεια**:

```
python training/voice/eval_router.py    →  849/849   100%    (πάνω στα ίδια τα δεδομένα)
python training/voice/eval_heldout.py   →   48/52    92,3%   (φράσεις εκτός δεδομένων)
```

Το πρώτο μετρά πάνω στο `intents_el.json`, το σύνολο από το οποίο γράφτηκαν τα
μοτίβα: βαθμολογεί τον εαυτό του με τις δικές του ερωτήσεις. Είναι χρήσιμο ως
δίχτυ παλινδρόμησης — και μόνο.

Το δεύτερο μετρά σε 52 φράσεις γραμμένες στο χέρι, με άλλα ρήματα και συνώνυμα.
**Πριν τη δουλειά στον router ήταν 65,4%.** Ό,τι κερδήθηκε κερδήθηκε από
γενικεύσεις (αγγλικά κλειδιά, ηχητική ισοπέδωση, ανοχή σε λέξη ανάμεσα στο ρήμα
και το ουσιαστικό), όχι από κυνήγι μεμονωμένων διατυπώσεων.

Αυτό που **μένει** και δεν λύνεται με άλλο μοτίβο:

* ελεύθερη διατύπωση όπου η πρόθεση κρύβεται στη σύνταξη: «δείξε μου τι
  τιμολόγια **έχω βγάλει**» είναι η λίστα, όχι νέα έκδοση,
* επωνυμία γραμμένη σε **άλλο αλφάβητο** από ό,τι έχει το πελατολόγιο
  («ΜΕΓΚΑΤΕΚ» για «MEGATECH»),
* στοιχεία έκδοσης χωρίς λέξεις-οδηγούς: «τιμολόγιο για τη ΞΕΝΤΕ, μεταφορικά,
  120 ευρώ» — ο άνθρωπος καταλαβαίνει από τα κόμματα, ο regex όχι,
* ερωτήσεις **«πώς γίνεται»**, που δεν είναι εντολές καθόλου (`faq_el.json`, §4).

Αυτά τα τέσσερα είναι το πραγματικό τίμημα του να μην υπάρχει μοντέλο.

## 2. Η αρχιτεκτονική-στόχος

Το μοντέλο μπαίνει ως **δεύτερη γραμμή**, όχι ως αντικαταστάτης:

```
κείμενο ─► regex router ──(βρήκε)──► ενέργεια
              │
           (δεν βρήκε)
              ▼
        τοπικό LLM ─► JSON ─► επικύρωση ─► ενέργεια
                                 │
                            (άκυρο JSON)
                                 ▼
                       «δεν το κατάλαβα»
```

Γιατί όχι αντικατάσταση: ο regex είναι 0 ms και ντετερμινιστικός· το «πήγαινε
στα πρόχειρα» δεν έχει λόγο να περάσει από μισό gigabyte βαρών. Και όταν το μοντέλο
λείπει (server, παλιό build, χρήστης που δεν το κατέβασε), ο βοηθός συνεχίζει να
δουλεύει όπως σήμερα.

## 3. Το συμβόλαιο — τι επιστρέφει το μοντέλο

**Μόνο ένα JSON αντικείμενο**, με τα κλειδιά του [`Reply`](../../desktop/src/timologio/etimologio/assistant.py):

| Κλειδί | Τιμή | Ποιος το εκτελεί |
|---|---|---|
| `navigate` | `issue`, `documents`, `bulk`, `customers`, `products`, `series`, `drafts`, `credit`, `payments`, `schedule`, `stats`, `notifications`, `settings`, `companies`, `admin`, `card` | `shell.open_section` / `showView` |
| `command` | `manual`, `tour`, `backup`, `logout`, `palette`, `refresh`, `home`, `back`, `speak:on`, `speak:off`, `card:<ΑΦΜ>`, `company:<ΑΦΜ>` | `shell._assistant_command` |
| `dialog` + `prefill` | `customer` \| `product` | `shell._assistant_dialog` |
| `fetch` | `stats:year`, `stats:month`, `notifications`, `customers_count`, `products_count` | `shell._assistant_fetch` |
| `draft` | `{vat, name, item, price, qty, withholding_pct}` | `issue.prepare_draft` — **πάντα πρόχειρο** |
| `say` | ελεύθερο κείμενο | το panel |

Ό,τι δεν είναι σε αυτόν τον πίνακα **απορρίπτεται πριν εκτελεστεί**. Το μοντέλο
δεν είναι έμπιστη πηγή εντολών: είναι πρόταση που περνά από φίλτρο.

## 4. Δεδομένα εκπαίδευσης

**Τρία σύνολα, ένα συμβόλαιο.** Και τα τρία βγάζουν `{instruction, input,
output}`, και η `instruction` λέει ποια δουλειά είναι — γι' αυτό χωράνε σε ένα
LoRA και σε ένα φόρτωμα στη μνήμη.

| Αρχείο | Ρόλος | Πλήθος |
|---|---|---|
| [`tts_normalizer_el.json`](tts_normalizer_el.json) | κείμενο → εκφώνηση (ΑΦΜ ανά 2ψήφια, «2.1» → «δύο τελεία ένα») | 1.415 |
| [`intents_el.json`](intents_el.json) | εντολή → JSON ενέργεια (ελληνικά + αγγλικά) | 849 |
| [`faq_el.json`](faq_el.json) | ερώτηση «πώς δουλεύει» → JSON απάντηση με `say` + `navigate` | 211 |

```bash
python training/voice/build_dataset.py
python training/voice/build_intents.py
python training/voice/build_faq.py
python training/voice/check_datasets.py   # ΠΑΝΤΑ πριν τη GPU
```

Το `check_datasets.py` διαβάζει το συμβόλαιο **από τον κώδικα** (`assistant.NAV`,
`assistant.COMMANDS`) και σταματά ό,τι η εφαρμογή θα πετούσε: άγνωστη ενότητα,
εντολή που δεν υπάρχει, `draft` χωρίς ΑΦΜ ή όνομα, ψηφίο που ξέμεινε σε έξοδο
εκφώνησης. Μία ώρα GPU κοστίζει περισσότερο από δύο δευτερόλεπτα ελέγχου.

### Το `faq_el.json` — γιατί υπάρχει

Ο δρομολογητής απαντά στο **τι να κάνω**: «άνοιξε τα πρόχειρα» → πάει στα
πρόχειρα. Δεν απαντά στο **πώς γίνεται**: «πώς ακυρώνω τιμολόγιο;», «γιατί λέει
αναμονή ενώ το κατέβασα;», «πού βάζω το κλειδί της ΑΑΔΕ;». Σήμερα ο βοηθός λέει
«δεν το κατάλαβα» και ο λογιστής ανοίγει το PDF.

Το περιεχόμενο είναι αντιγραμμένο **από τα ίδια τα εγχειρίδια**
([`manual.py`](../../desktop/src/timologio/gui/manual.py),
[`help.py`](../../desktop/src/timologio/etimologio/help.py), τον πίνακα `MANUAL`
στο [`app.php`](../../app.php)) — όχι από μνήμη. Όταν αλλάζει η εφαρμογή,
αλλάζει και εδώ, στην ίδια συνεδρία.

**Τα συνθετικά δεδομένα δεν αρκούν για παραγωγή.** Το πραγματικό σύνολο μαζεύεται
από την ίδια την εφαρμογή: στο `?stt=1` ([etimologio.php:4185](../../etimologio.php:4185))
πρόσθεσε προαιρετική καταγραφή `{ό,τι ακούστηκε, τι έκανε ο χρήστης μετά}` σε
JSONL μέσα στον φάκελο δεδομένων, με ρητή συγκατάθεση και **χωρίς αποστολή
πουθενά**. 300-500 αληθινές εντολές αξίζουν όσο 5.000 συνθετικές.

## 5. Εκπαίδευση

```bash
pip install unsloth
python training/voice/train_unsloth.py                 # και τα τρία σύνολα
python training/voice/train_unsloth.py --task tts      # μόνο η εκφώνηση
python training/voice/train_unsloth.py --epochs 5 --rank 32
```

* **Μοντέλο βάσης: `unsloth/Qwen3.5-0.8B`** (q4_k_m 533 MB, Apache 2.0, 201
  γλώσσες). Το σκεπτικό — και οι υποψήφιοι που απορρίφθηκαν — στο
  [MODELS.md §3](MODELS.md). Με `--model unsloth/Qwen3-0.6B` γυρίζεις στα
  397 MB· με `Qwen3-1.7B` παίρνεις καλύτερο τονισμό στο 1,1 GB.
* **Αν χρησιμοποιήσεις Qwen3 (όχι 3.5): απενεργοποίησε το thinking.** Βγάζει
  `<think>…</think>` πριν από την απάντηση, που για δρομολογητή είναι και
  καθυστέρηση και σπασμένο parsing. Στο llama.cpp: `--chat-template-kwargs
  '{"enable_thinking":false}'`, ή σκέτο `/no_think` στο prompt.
* **Ένα LoRA ή τρία;** Οι τρεις δουλειές χωράνε σε ένα μοντέλο επειδή η
  `instruction` τις ξεχωρίζει — και ένα μοντέλο σημαίνει μία φορά φόρτωμα στη
  μνήμη. Ξεκίνα ενωμένα· χώρισε μόνο αν μετρηθεί ότι η μία χαλάει την άλλη.
* **`--rank`**: 16 αρκεί για μετασχηματισμό (εκφώνηση, δρομολόγηση). Το FAQ
  όμως προσθέτει **γνώση**· αν οι απαντήσεις βγαίνουν αόριστες, δοκίμασε 32
  πριν κατηγορήσεις το μοντέλο.
* **Θερμοκρασία 0** στην εκτέλεση. Ο δρομολογητής δεν έχει λόγο να είναι δημιουργικός.
* **Γραμματική GBNF**: το llama.cpp δέχεται `--grammar-file` που **επιβάλλει** έγκυρο
  JSON με τα επιτρεπτά κλειδιά. Είναι ο φθηνότερος τρόπος να μη δεις ποτέ
  μισοτελειωμένο JSON — γράψε τη γραμματική από τον πίνακα του §3.

## 6. Ενσωμάτωση, βήμα-βήμα

1. **Πακετάρισμα.** `llama-cli.exe` + `.gguf` στο `desktop/installer/llm/`.
   Στο [`timologio.spec`](../../desktop/installer/timologio.spec) αντίγραψε το μοτίβο
   του `WHISPER`: λίστα αρχείων που κρατάμε, ώστε ένας παλιός φάκελος build να μη
   φέρνει 2 GB παραδειγμάτων.
2. **Ανακάλυψη διαδρομών.** Πρόσθεσε `llm`/`llm_model` στο `voice_engine()`
   ([etimologio.php:3973](../../etimologio.php:3973)) — ίδιος μηχανισμός με Piper/whisper:
   πρώτα σταθερά του `config.php`, μετά συμβατικές θέσεις.
3. **Σταθερές.** Στο [`service.py`](../../desktop/src/timologio/etimologio/service.py),
   δίπλα στα `PIPER_EXE`/`WHISPER_EXE`, γράψε `LLM_EXE` και `LLM_MODEL`.
4. **Endpoint.** `?llm=1&text=…` στο `etimologio.php`, δίπλα στο `?tts=1`:
   `proc_open` με `--grammar-file`, timeout, και **501 όταν λείπει το μοντέλο** —
   ίδια συμπεριφορά με τη φωνή, ώστε το UI να ξέρει ήδη τι να κάνει.
5. **Desktop.** Στο `Assistant.handle()`, στο σημείο που σήμερα επιστρέφει
   «Δεν το κατάλαβα», κάλεσε το μοντέλο. Ο `Assistant` **δεν κάνει δίκτυο ούτε
   subprocess μόνος του** (είναι ο λόγος που δοκιμάζεται χωρίς Qt): πέρασέ του
   ένα `resolver: Callable[[str], dict | None]` στον constructor, και δώσε την
   πραγματική υλοποίηση από το `assistant_panel.py`.
6. **Web.** Στο `cbHandle`, στο ίδιο σημείο (πριν το τελικό «Δεν το κατάλαβα»),
   `await api({llm:1,text:t})` και εκτέλεση μέσα από τον ίδιο έλεγχο του §7.
7. **Επικύρωση.** Μία συνάρτηση, κοινή λογική σε Python και JS:
   άγνωστο κλειδί → πέταξέ το· `navigate` εκτός λίστας → άκυρο· `command` εκτός
   λίστας → άκυρο· `draft` χωρίς `vat`/`name` → άκυρο· οτιδήποτε μυρίζει οριστική
   έκδοση → άρνηση με το σταθερό μήνυμα.
8. **Δοκιμές.** `eval_router.py` με τον resolver του μοντέλου, και νέα tests στο
   [`test_assistant.py`](../../desktop/tests/test_assistant.py) με fake resolver —
   ένα που επιστρέφει έγκυρο JSON, ένα σκουπίδια, ένα που ζητά οριστική έκδοση.

## 7. Όρια που δεν διαπραγματεύονται

* **Ποτέ οριστική έκδοση.** Το ΜΑΡΚ βγαίνει μόνο από το κόκκινο κουμπί, με
  ανθρώπινη επιβεβαίωση. Το `intents_el.json` περιέχει παραδείγματα *άρνησης*
  ακριβώς γι' αυτό.
* **Τίποτα δεν φεύγει από το μηχάνημα.** Ίδιος κανόνας με Piper/whisper: τα λόγια
  του λογιστή και τα ΑΦΜ των πελατών δεν ταξιδεύουν.
* **Ο regex μένει.** Είναι το δίχτυ ασφαλείας όταν το μοντέλο λείπει ή αργεί.
* **Προϋπολογισμός μεγέθους.** Ο installer είναι ήδη 444 MB. Το Qwen3.5-0.8B σε
  q4_k_m (533 MB) τον πάει σχεδόν στο gigabyte — το Qwen3-0.6B (397 MB) στα
  ~840 MB. Αν αυτό δεν είναι αποδεκτό, το μοντέλο γίνεται **προαιρετικό
  κατέβασμα** — ίδιο μοτίβο με το ελληνικό Vosk στο `build.ps1 -WithVoice`.

## 8. Σειρά υλοποίησης

| Φάση | Τι | Κέρδος | Κόστος |
|---|---|---|---|
| 1 ✅ | Διευρυμένες εντολές σε regex | 74% → 87% κάλυψη | 0 MB |
| 2 ✅ | Τρία σύνολα δεδομένων, 2.458 παραδείγματα, με έλεγχο συμβολαίου | έτοιμα για Unsloth | 0 MB |
| 3 ✅ | Κανονικοποιητής εκφώνησης **ως κώδικας** — `speakable.py` + `speakable.php` | σωστά ΑΦΜ, ποσά, ημερομηνίες και τύποι στη φωνή | **0 MB** |
| 4 | Whisper fine-tune στο λεξιλόγιο (Unsloth — δες [MODELS.md](MODELS.md) §1) | λιγότερα «τυστικά» | 0 MB (ίδιο μέγεθος μοντέλου) |
| 5 | LLM δρομολογητής + FAQ ως fallback | ελεύθερος λόγος, απαντήσεις «πώς γίνεται» | ~530 MB |

**Η φάση 3 έγινε, και δεν χρειάστηκε μοντέλο.** Ο κανόνας που θα μάθαινε το LLM
(ΑΦΜ ανά δύο ψηφία, «12.100,00 €» → «δώδεκα χιλιάδες εκατό ευρώ», «2.1» → «δύο
τελεία ένα») ζει πλέον στο **προϊόν**:

| Αρχείο | Πού καλείται |
|---|---|
| [`speakable.py`](../../desktop/src/timologio/etimologio/speakable.py) | `speech._speakable`, πριν από τον Piper της εφαρμογής υπολογιστή |
| [`speakable.php`](../../speakable.php) | `?tts=1` του [`etimologio.php`](../../etimologio.php), πριν από τον Piper του server |

Δύο υλοποιήσεις γιατί η φωνή καλείται από δύο πλευρές — και ένα test που τις
βάζει **δίπλα-δίπλα** σε 30 πραγματικές προτάσεις και απαιτεί ίδιο κείμενο
(`test_speakable.py`). Χωρίς αυτό, η ίδια πρόταση θα ακουγόταν αλλιώς στην
εφαρμογή και αλλιώς στον browser, και κανείς δεν θα το καταλάβαινε.

Το `build_dataset.py` **δανείζεται** τον ίδιο μετατροπέα αντί να τον αντιγράφει:
το σύνολο εκπαίδευσης παράγεται πια από τον κώδικα που τρέχει στην πράξη, οπότε
δεν μπορούν να ξεφύγουν σιωπηλά.

Κόστος: **0 MB, 0 ms**. Το μοντέλο μένει για ό,τι δεν προβλέψαμε — ξένα ονόματα,
ορθογραφία εκτός λεξιλογίου — και κυρίως για τη φάση 5, όπου απαντά σε ερωτήσεις
που κανένας regex δεν πιάνει.
